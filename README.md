# Ricardo C Freitas - Site de Autor

Site estatico para divulgacao dos livros de Ricardo C Freitas, com destaque para `A arte de viver` e uma biblioteca visual com capas salvas da Amazon.

## Como abrir

Abra o arquivo `index.html` no navegador.

## Como publicar no GitHub Pages

1. Envie todos os arquivos deste projeto para um repositorio no GitHub.
2. No repositorio, acesse `Settings > Pages`.
3. Em `Build and deployment`, escolha `Deploy from a branch`.
4. Selecione a branch principal e a pasta raiz.

## Edicao rapida

No site, clique em `Editar`.

Senha padrao: `admin123`

As alteracoes feitas pelo painel ficam salvas no navegador usado para editar.
